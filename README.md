# 🔬 DR Detect - Diabetic Retinopathy Screening

## Smart India Hackathon 2026 | Problem ID: 26038

### Problem Statement
Explainable AI for Diabetic Retinopathy Screening in Rural India

### Solution
A web-based AI system that:
- Screens retinal fundus images for diabetic retinopathy
- Provides severity grading (0-4 scale)
- Generates clinical recommendations
- Uses explainable AI (Grad-CAM) for transparency

### Features
✅ User-friendly web interface  
✅ Automated DR severity classification  
✅ Clinical recommendations based on severity  
✅ Explainable AI with attention heatmaps  
✅ Optimized for rural healthcare settings  

### Tech Stack
- **Frontend:** Gradio (Python)
- **Backend:** TensorFlow/Keras
- **Model:** ResNet-50 / EfficientNet
- **Dataset:** APTOS 2019, IDRiD
